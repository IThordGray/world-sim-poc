# Out of scope

Ideas rejected for good, one file per concept (`add-to-calendar.md`), so the same request doesn't
come back and get argued again. Wanted but not now is not this: that goes in your issue
tracker.

Before anything new is planned, check the file names here. When a request matches one, say so and
give the file's reason before going further; the human may confirm, reconsider (delete the file) or
say it's different.

A file says what was rejected and why, in a few plain paragraphs. The reason must be durable
("not part of the product because…"), never temporary ("too busy now"). Under `## Prior requests`,
one line per time it came up.
